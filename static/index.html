DNS intelligence

Query public A, AAAA, MX, NS, TXT, CAA, SOA, and CNAME records. DNS queries contact external resolvers and require authorization.

Passive subdomain discovery

Enumerate names published in Certificate Transparency logs through crt.sh. Unverified names are not proof of live hosts, ownership, or exploitable assets.

Registration intelligence — RDAP

WHOIS concepts implemented via the modern public RDAP protocol. Registry privacy may hide contact data.

TLS certificate details

One validated TLS connection to port 443, showing protocol, cipher, issuer, expiry and certificate hostnames. Only for approved targets.

Safe search operator builder

Generate domain-scoped, non-invasive Google/Bing searches. No login discovery, sensitive-file hunting, or mass scraping is performed.

Email header analysis

Paste raw RFC 5322 headers. Analysis runs entirely in the local FastAPI process; it doesn't submit message content to any external service.

Photo EXIF privacy check

Inspect image metadata, camera details, timestamps and embedded GPS coordinates. Files are processed in memory and not stored on disk.
